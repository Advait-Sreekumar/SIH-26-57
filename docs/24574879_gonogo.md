### 2. Annotation Format

- Format: YOLO detection (.txt, 5-column: class cx cy w h), confirmed by inspection
- Class 0 = MILCO (Mine-Like Contact Object): 437 annotated objects across 1,170 images
- Class 1 = NOMBO (Non-Mine Bottom Object): 231 annotated objects across 1,170 images
- Confirmed by `Training/obj.names.txt`: first line = MILCO, second line = NOMBO
- 866 of 1,170 images have empty annotation files (true negatives / background)
- Non-annotation .txt files (`obj.names.txt`, `yolov4-custom.txt`) are in `Training/` only

MILCO=0, NOMBO=1 as stated in paper. Format match confirmed. PASS.

### 3. Image Sizes

Sampled images are 416x416 or 1024x1024 px (resized SSS waterfall segments). These are
substantially smaller than AI4Shipwrecks images (2476x1728 px). Not a blocker — the model
accepts arbitrary sizes via tiled inference.

### 4. Training Folder Contents

The `Training/` folder contains the original authors' training artefacts:
- `yolov4-custom.txt`: Darknet YOLOv4 config (classes=2 confirmed)
- `obj.names.txt`: class names file
- `yolov4-custom_5000.weights`: their trained YOLOv4 weights (256 MB) — NOT USED
- `Real_time_object_classifier.ipynb`: their training notebook — NOT USED

We run our shipwreck U-Net on the images only. Their weights and config are not used.

### 6. Sensor Compatibility — Domain Mismatch (documented, not a blocker for our purpose)

| Property | AI4Shipwrecks (our training set) | Santos 2024 |
|----------|----------------------------------|-------------|
| Platform | Towfish (surface-towed) | AUV-mounted |
| Frequency | ~132 kHz | 900-1800 kHz (dual-freq) |
| Swath | Wide (~50-100m/side) | Narrow AUV swath |
| Target class | Shipwrecks | MILCO (Mine-Like Contact Objects) / NOMBO (Non-Mine Bottom Objects) |
| Image size | 2476x1728 px (typical) | 416x416 or 1024x1024 px |
| Water type | Great Lakes (freshwater) | Coastal (unspecified) |

This is the same class of domain mismatch documented in `docs/subpipe_gonogo.md` for
SubPipe. SubPipe was closed NO-GO due to GPL-3.0 licence. This dataset is CC-BY-4.0,
so licence is not the blocker here.

The domain mismatch is NOT a blocker for our specific purpose: we are not fine-tuning,
not claiming the model works on AUV data, and not claiming mine-detection capability.
We are measuring whether features learned on towfish shipwreck images transfer at all
to a completely different SSS domain. The mismatch is the point.

### 7. Annotation Type Mismatch — methodology defined

- This dataset: YOLO bounding boxes (normalised cx cy w h)
- Our model output: pixel-level segmentation masks

Comparison methodology: run our U-Net on each image, derive a bounding box from the
predicted mask (tight axis-aligned bbox around each connected component), compute
IoU-of-boxes against the ground-truth YOLO bbox.

This is a weaker metric than our primary pixel IoU — it measures whether the model fired
in approximately the right region, not whether it delineated the shape correctly. The
results are NOT comparable to our test IoU 0.427 (pixel-level, same-domain).

Do NOT use: mine detection, mine classification, mine-detection model, MILCO detection,
or any language that could be read as a mine-detection capability claim.

For our purposes these are man-made-object-vs-natural-seafloor annotations in a different

## Verdict

**CONDITIONAL GO** — subject to:

1. CC-BY-4.0 attribution in all docs and UI copy
2. Never label this work as mine detection — use the approved framing label above
3. Report IoU-of-boxes only; state ground truth is bounding-box only
4. Report domain mismatch explicitly: AUV-mounted vs towfish SSS
5. If detection rate is low (expected), document that as the finding — do not adjust
   thresholds post-hoc
6. This is a generalization characterization only — not a second validated detection
   class and not a shipped feature

**What this check will tell us:** Whether shipwreck-trained features (acoustic shadow +
target highlight patterns) transfer at all to AUV-surveyed seabed in a different survey
geometry. A low detection rate is an honest and useful finding.

**What it will NOT tell us:** Nothing about mine detection. Nothing about AUV deployment
readiness. Nothing beyond what 1,170 images from a single AUV survey campaign can support.
